# 从 v2.8～v2.12 安全升级到 v2.13.0

适用于 Windows 上已有作业数据的助教，包括从 v2.11 直接升级。准备 Node.js 24.13.0 或更新的兼容版本。推荐 Git，方便以后获取源码。没有 Git 也可选 ZIP。

## 1. 关闭旧平台并运行升级助手

1. 保存评分和作业设置，等正在运行的批改、参考整理结束。记下旧平台启动窗口里“数据保存在”后面的完整路径。默认是旧程序里的 `data` 文件夹。若用过自己的启动脚本或 `.env`，以实际设置的路径为准。
2. 在旧平台的启动窗口按 **Ctrl+C**，或用原来的关闭脚本。升级期间保持旧平台关闭。
3. 打开 Windows PowerShell，复制整段命令。按提示输入旧数据路径，再选 **1 Git** 或 **2 ZIP**。

```powershell
$helper = Join-Path $env:TEMP ('grading-upgrade-' + [guid]::NewGuid().ToString('N') + '.ps1')
[Net.ServicePointManager]::SecurityProtocol = [Net.SecurityProtocolType]::Tls12
Invoke-WebRequest -UseBasicParsing -ErrorAction Stop -Uri 'https://raw.githubusercontent.com/Benhuangsuan/linear-algebra-grading-desk/main/scripts/upgrade-v2.13.ps1' -OutFile $helper
powershell.exe -NoProfile -ExecutionPolicy Bypass -File $helper
```

助手先完整备份旧数据，再用 Git 或从 [v2.13.0 Release](https://github.com/Benhuangsuan/linear-algebra-grading-desk/releases/tag/v2.13.0) 下载固定版本，安装并构建。它会核对文件、检查新版能否完整读取历史记录，并在独立目录准备正式数据。升级过程不调用 AI，也不需要手动创建测试作业。

看到 **“升级完成”** 后，把窗口显示的目录路径粘贴到文件资源管理器地址栏。里面的 `backup` 是备份，`app` 是新版程序，`Start-v2.13.cmd` 是日常启动入口。若检查失败，按提示处理后重试。请保留旧程序、旧数据和已生成的备份。

## 2. 配置自己的 AI API

**原来用 Windows 用户变量配置过**，通常继续使用原 Key。**原来用旧项目的私人 `.env`**，请在新版 `app` 目录重新建立私人 `.env`，只迁移需要的 AI 设置，别复制旧的 `DATA_DIR` 或 `PORT`。

- **DeepSeek**。没有 Key 时，登录 [DeepSeek 开放平台的 API Keys](https://platform.deepseek.com/api_keys)，创建并私下保存自己的 Key。确认账号有可用余额。
- **Qwen**。可在 [阿里云百炼](https://help.aliyun.com/zh/model-studio/get-api-key) 创建自己的 Key。按默认配置使用中国内地（北京）的 Key，并确认账号可用。

选择以下一种保存方式。已配置过的变量可直接检查或修改。

| 设置 | 填写内容 |
| --- | --- |
| `DEEPSEEK_API_KEY` | 选 DeepSeek 时填自己的 Key |
| `DASHSCOPE_API_KEY` | 选 Qwen 时填自己的 Key |
| `AI_ALLOW_PAID` | 明确同意付费调用后填 `true` |

- **Windows 用户变量（推荐）**。开始菜单搜索 **编辑账户的环境变量**，在“用户变量”中按表新建或编辑。
- **私人 `.env`**。在记事本中按 `变量名=值` 每行填写一项，如 `AI_ALLOW_PAID=true`。选择“所有文件”，以 UTF-8 另存为新版 `app` 里的 `.env`（文件名不要带 `.txt`）。同名 Windows 环境变量优先，建议同一项只在一处设置。

Key 只保存在自己电脑。不要发到 GitHub、聊天群、公开文档或日志。修改后关闭旧终端或正在运行的平台，再从文件资源管理器打开启动文件。新进程在启动时读取配置，浏览器刷新无法更新这些设置。

## 3. 启动并开始批改

1. 双击升级目录里的 **`Start-v2.13.cmd`**，保持窗口打开。在浏览器打开 <http://127.0.0.1:3000>，确认显示 **2.13.0**，进入原来的课程与作业。
2. 核对并保存题目清单、参考答案与扣分规则。到“学生作业”勾选本次要批改的作业，点 **AI 批改已选**，选择 **DeepSeek** 或 **Qwen**。看到 **已配置密钥** 表示程序读到了 Key，可跳过可能收费的“测试连接”。
3. 点击 **快速检查**。移出有问题的文件后，可直接使用其余通过的结果。核对每份及整批预算，确认课程允许发送参考与作业页面，核对页面已去除身份信息，再完成弹窗里的确认项并点击 **开始 AI 批改**。批改完成后人工核对扣分再确认成绩。

**以后启动**。电脑重启后仍双击同一个 `Start-v2.13.cmd`。它会使用这次升级的数据和本机的 API 配置，无需再输入路径。可为它创建桌面快捷方式，请将启动文件留在原目录。

**关闭平台**。等当前工作保存完成后，在启动窗口按 **Ctrl+C**。如果询问是否终止批处理，输入 `Y` 并回车。

**网页打不开**。先查看启动窗口是否仍开着，并已显示 v2.13.0 的网址。若提示端口占用，关掉旧平台或已开的 v2.13 窗口再试。若提示缺少数据，检查启动文件与同目录的 `app`、`data` 是否齐全，再按窗口提示处理。

## 需要回退时

先关闭新版，保留新版数据。若升级后还没有新增作业或评分，可用旧程序和原数据恢复使用。若已产生新作业、成绩、规则或费用，请先备份新版数据并确认怎样保留新增记录。新旧程序各用自己的数据目录，备份和数据都不要上传。
