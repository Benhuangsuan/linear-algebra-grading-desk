# v2.13.0 发布说明

学生批改改为免费快速检查：全部所选文件先显示检查状态，逐份完成原页处理。助教可移出问题文件，直接批改其余已通过者；不再等待整批费用预估或确认0.30元阈值。每份和本批预算、每次请求前的持久化预留、未知费用、失败证据续跑与显式付费授权继续保留。

扣分原因要求采用助教面对学生的自然表述。扣分项旁可免费查看原理由、规则和原稿；主动追问时每次确认发送页面、去标识和预算。对话仅在私有数据目录保存，可查看、删除，解释不会自动改分。

修改评分时，正确/等价解仅显示“助教备注（不扣分）”，做错/未完成、未做、未检索到或需核对仅显示“扣分原因”。正确题可填写无扣分备注。只有有备注的正确题额外出现在原展开区域；备注随审核及历史保存，不改变成绩、漏题数量或CSV两列格式。

继续沿用v2.12 PDF图像优化、完整分批识别、跨页证据和失败恢复。本轮不开发大文件压缩，上传上限仍为30 MiB、1～100页；不重新计算历史成绩或改写原费用。新增兼容的私有对话表，旧记录无需补填备注。

自动测试使用合成资料和模拟API，新增浏览器流程可运行 `npm run test:grading-ux`。模型实际数学质量仍需人工核对。本版本已完成验收，公开源码不包含个人课程、学生资料、参考原件、数据库、模型响应或密钥。

首次安装：下载本版本源码，在项目根目录运行 `npm.cmd ci`、`npm.cmd run build`、`npm.cmd start`，打开 http://127.0.0.1:3000 。无需Key即可人工评分。已有数据请先阅读[安全升级指南](../升级到v2.13.md)，完整流程见[助教指南](../助教本地部署与使用指南.md)。
