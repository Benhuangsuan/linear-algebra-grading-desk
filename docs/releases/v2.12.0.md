# v2.12.0 发布说明

本版本已通过本地验收。公开源码不附学生资料、参考答案、数据库、模型响应或API凭据。

- 高分辨率扫描页自动控制尺寸与JPEG编码，保留完整全景及必要的重叠细节，不再固定3倍放大所有页面。
- 保留46MiB请求保护，预检包含全部图像及实际请求参数；大小、上下文、输出额度和预算分别检查。
- 仍超限时自动分批识别全部参考及学生页，汇总整份跨页证据后评分；不按每个分页重复扣分。未完成页面不判漏做；不清晰证据中的漏题候选改为待确认。
- 分批结果只保存本机私人数据目录。失败、超时、取消或重启后不自动收费重试；明确重试时复用同一原稿、规则、模型及额度下的成功批和成功评分组，不重复记账。暂停在当前调用完成后停止后续调用，继续仍遵守原预算。
- 所有评分组完成后一次保存本次建议；失败保留原人工结果和历史。原有参考答案历史、扣分单元、成绩确认及CSV继续适用。

本轮仅本地合成API与自动/浏览器测试；没有新增真实模型质量或费用基准。复杂手写、图形和跨页证明仍须人工逐项复核。分批的保守预估可能明显增加，系统不会为了通过而自动增额。极端页超过资源上限或单题完整证据仍超限时安全停止，不伪装成功。

升级时应完整备份私人DATA_DIR（包括数据库及WAL/SHM、上传、缓存、原响应和费用），在独立数据副本演练后再切换，不覆盖唯一数据库。新增`grading_runs`表幂等创建；不重算已有成绩、不重写旧费用。不要用旧程序直接读取升级后的唯一数据副本。

首次安装：下载本版本源码，在项目根目录执行 `npm.cmd ci`、`npm.cmd run build`、`npm.cmd start`，打开 http://127.0.0.1:3000 。无需Key即可人工评分。已有数据请先读[安全升级指南](../升级到v2.12.md)，完整操作见[助教指南](../助教本地部署与使用指南.md)。
