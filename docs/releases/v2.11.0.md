# v2.11.0 发布说明

本次公开发布包含2.9、2.10和2.11的已验收改进；不单独补发两个中间版本的Release。源码与文档采用MIT，用户自有教材、参考答案和学生作品不随源码分发，也不属于MIT授权范围。

## 参考答案整理

- 作业范围支持自由中文。识别补充章、小节、讲义题/附加题、“补充题”等非数字标识；不同题组即使数字相同也分别保留，跨页解答和来源页保持关联。
- 修复普通教材章节题号列表回归，保留只有题号的“仅检查完成”题。材料明确要求全部批改时，新候选均采用“批改正确性”；原人工配置保持优先。
- 默认推荐AI，可一次选择多份PDF并识别全部原页，先预估单一总预算再开始。默认选中、上传或打开页面均不收费；免费自动整理和按文字整理仍在本机处理，三种方式都需要人工校对。
- 按文件保存完整/部分草稿及历史版本。其他文件失败，已完成结果仍可免费查看、跨任务合并，采用后还要“保存设置”。单一版本直接查看，多版本可选择；不同文件同号但内容冲突须选择。
- 失败文件可先免费复验已保存响应，或重新预估后单独重试；长文件尽量复用有效分页。新版本失败时旧完整草稿仍在，不自动覆盖题目、人工规则或成绩。
- 已有结果再次整理时，明确付费开始后显示“使用已有结果／继续重新整理／取消”及30秒默认继续倒计时。失焦、离线、页面中断或预估/规则变化会取消；刷新与服务重启不自动续费。确认后请留意倒计时，避免重复付费。
- 新响应及结果保存在本机私人DATA_DIR，不保存思考原文，不在普通界面展示开发诊断。旧版未保存的响应无法补回，来源不明确的旧草稿须对照PDF。

## 保留的评分与数据能力

独立小问计分、人工审核/改判、历史快照、姓名/十位学号校对、两列CSV继续保留。解答题默认整题，仅明确独立的小题逐项计分；两个证明方向不会仅因带a/b就自动独立扣分。已有成绩不因规则变化重算，已确认成绩须明确重开审核。

## 安装与升级

首次安装按[助教指南](../助教本地部署与使用指南.md)，Node.js >=24.13.0，运行`npm.cmd ci`、`npm.cmd run build`、`npm.cmd start`。无Key可人工评分，真实AI由每位助教配置自己的账号并承担费用及材料授权责任。

v2.8及中间开发版用户必须按[安全升级指南](../从v2.8升级到v2.11.md)先完整备份，在新程序/数据副本演练，再从最新备份创建新正式库。不要覆盖唯一数据库或使用改动过的演练库。2.11增加参考结果/响应索引，保留旧成绩、规则、费用与任务；恢复草稿不等于自动采用。回退须保留新写入，旧程序不直接读取新库。

## 验证边界

发布检查使用合成PDF、虚构身份和模拟API，验证解析、费用保护、恢复/重试、规则保护与人工闭环；不进行付费AI请求。测试覆盖不等于任意数学内容准确：扫描件、公式、题干/参考解和图形归属仍可能需要人工修正。每次作业先与独立人工批改的代表样本对照，所有扣分和不确定项复核、确认后再导出。
