# 2.8.0 本地开发修改说明

基于已验收的2.7.0，尚未合并、发布标签或Release。

- 修复新人工评分和Mock直接按父题创建结果的问题，复用视觉AI已有的单元转换；独立小问使用稳定childId、父题关联、个别扣分与参考页。新课程评分每单元只计一次错误，不叠加父题扣分。
- 人工编辑、扣分展示、汇总和CSV按同一评分快照工作；a、b均漏做默认扣0.4，导出 `9.6，漏2题`。普通解答题默认整题，完成性题部分实质作答不扣分。
- 旧父题成绩不自动拆分或重算。明确重开后可选择按当前题目重新人工评分；原评分和报告保留在修订记录，不发起AI调用，也不修改费用记录。重新录入受提交版本、题目版本及归档状态保护。
- 删除选择机制常驻解释、正常已保存状态等重复小字；保留操作受阻、未保存、费用、隐私及历史重判提醒，沿用原字号和布局。

无新依赖、无数据库结构迁移；原通用赋分及历史错误处数规则保留。历史成绩、现有课程规则及正式平台不会因启动新版自动升级。
