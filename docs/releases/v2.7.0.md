# 2.7.0 本地开发修改说明

尚未发布新标签或 GitHub Release，基于已验收的 2.6.0。

- AI 操作区说明当前阻塞原因，显示实际未校对小问数量并可前往设置；失效预估、预算和重复批次均有指引，保留后端安全拦截。
- 网页标题、帮助、页脚、启动提示和健康检查统一读取程序包版本；参考页表单对齐，关键控件字号更清晰，窄屏转为单列。
- CSV 保持姓名、成绩两列，成绩为 `10`、`9.8` 或 `9.6，漏2题`；使用最终有效扣分记录及既有独立计分口径，不把答错算成漏做。
- 普通界面及模拟接口默认关闭；开发测试显式设置 `ENABLE_MOCK_UI=true`。历史模拟结果仍可查看并明确标注，人工评分不依赖 AI 配置。
- 新上传文件识别独立十位学号，支持前导零与常用分隔符，歧义留空；列表可人工修改、保存或清空。旧身份不自动补录，同名新提交不覆盖原信息，模型请求不新增学号。

无新依赖、无数据库结构迁移，不自动重算成绩、重发模型请求或扩大预算。旧非十位学号原样保留；修改该字段时须十位数字或清空。PDF 页面中的身份信息仍须使用者自行处理。
