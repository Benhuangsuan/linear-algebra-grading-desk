# v2.4.0

供 Windows 助教本机运行的源码版本。首次安装请阅读[部署与使用指南](../助教本地部署与使用指南.md)。

- 课程、作业、参考材料及学生 PDF 管理；Mock 与纯人工评分；原稿预览、人工复核、确认、修订历史和两列 CSV。
- 父题与小问管理、独立扣分单元；指定学生视觉 AI 初评、未批改筛选、批次恢复和费用账本。
- DeepSeek / Qwen 适配及显式传输授权、预估绑定、预算门禁；输出额度可选，长页/大页全景与重叠分区保留原页码，局部放大失败保留初评待复核。
- 公开分发的测试改用合成参考 PDF/DOCX，不依赖私人附件、正式数据库或真实 API Key；默认本地 Mock / 人工功能无需付费。

本次分发整理不改既有评分、队列、API 接入与费用机制。源码不附个人数据、参考答案或学生材料；每位助教建立独立数据与账户配置。既有安装应先停止服务、备份自己的完整数据目录，再更新源码和依赖、构建、启动。

自动解析仍须校对，题干/参考解可能需人工修正。AI 数学质量、真实账户能力和最终账单须另行授权校准；未知用量仍保守预留，不能保证任何 PDF 或模型请求始终成功。

公开分发另包含 [依赖安全修复](../依赖安全与许可证.md)，并统一 PDF.js 与原生画布版本。源码安装仍使用锁文件和 npm.cmd ci。
