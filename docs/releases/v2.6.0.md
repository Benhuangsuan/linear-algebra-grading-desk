# 2.6.0 修改说明（本地开发，未公开发布）

- 参考页编辑明确区分已有列表和添加/更换表单，优先按文件内容中的小节推荐参考答案，无法唯一确定时留空。跨小节使用须确认；添加、更换、移除都有操作反馈，多页参考和父题图形共用保留。
- 未完成添加/更换选择时阻止误点“应用调整”。应用后先更新当前题目清单，点击“保存设置”才保存到本机；关闭未应用的修改会提醒，页面明确显示尚未保存状态。
- 参考答案整理、检查提醒、题目清单与扣分规则采用同级区域。两个实际等效的黑红选项合并为自动整理，原接口参数仍兼容；只按文字整理保留。
- 免费整理和 AI 辅助在同一入口，整理结果先供检查；显示当前题数、整理总数、新增/重合数及新上传文件识别数。默认只添加新题和新小问，已有人工内容和参考页须逐项选择才替换。
- AI 辅助必须明确确认材料、个人信息处理及费用，先预估再开始；切换、上传、保存都不会自动付费。取消准备、费用门禁、未知用量保护保留，一次尝试后清除授权与预估，不自动重复调用。
- 保存时额外检查参考文件属于当前作业且页码有效，失效引用会说明如何处理；不删除原 PDF，不改写旧成绩、评分快照或账本。

没有新增依赖或数据库迁移；原有评分、模型接入、预算和学生作业主界面保持。普通屏幕和窄屏操作均有回归，新增测试命令为 `npm.cmd run test:reference-workflow`。

更新前仍需停止服务、保留个人修改并备份完整数据目录。此文件是本地开发说明，不表示已经合并主分支、创建标签或发布 Release。
