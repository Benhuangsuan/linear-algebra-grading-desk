# 2.5.0 修改说明（本地待审阅）

以公开 `v2.4.0` 为基线。本轮没有推送、合并、创建新标签或发布 Release。

- 题目标识继续使用字符串，支持补充题、带序号的补充题及其他明确命名标题；保持原文顺序，多个补充题分别处理。别名提示进入特殊说明，编号不明确时仍须人工核对。
- 修复编辑弹窗中拖选文字、在弹窗外释放鼠标会意外关闭的问题。只有按下和释放均在遮罩上的真实点击才关闭；关闭、取消和 Escape 保留。
- 本地提取保留文字颜色、坐标、来源页及图形区域。可选择自动检测、本材料黑题干/红参考解、仅文本结构三种策略；保留父题公共条件和各小问题干/参考解。无颜色、扫描件、异常片段提供回退和人工提示。
- 图形与来源页关联到题目，父题图形由小问继承。使用渲染后的完整来源页，包含位图及矢量绘制，不依赖仅抽取内嵌图片；原件与图像缓存保留，编辑窗口可校对、补充或移除关联。
- 批改继续发送原有完整参考 PDF 图像，新增明确题目/来源页映射，不为普通题目重复附图。来源无效、已知图形缺关联时在发送前阻止；现有视觉模型与 `image_url` 格式保持不变。
- 可在折叠的解析选项中按需整理最多 4 个复杂来源页。必须主动同意传输和费用、确认去标识、预估并确认后才请求模型；预估绑定材料、页码、模型、输出额度、规则版本和预算。采用原有费用预留与结算机制，未知用量保留，不自动重试。上传、普通整理及保存不触发此调用。
- 辅助解析只返回可编辑候选，不决定评分规则。重整默认保留教师文字、ID、个别扣分及历史成绩；大题文字/来源和同编号小问须分别明确采用，最后核对并保存。新批改使用新快照，旧成绩和账本不自动重算。

升级没有数据库 DDL 迁移；新增信息均为可选 JSON 字段。旧数据仍可读取，旧文件的版面信息仅在明确整理时补充。已有配置不会自动获得新字段，请通过整理差异或手工关联来源页采用。复制题目配置或删除参考文件后，要重新核对来源文件是否属于当前作业。

公式、分数、矩阵与上下标的纯文本仍可能损失排版，应以关联原页为准。自动颜色检测不能保证符合任意课程约定，图形区域和边界也需要校对。视觉辅助不保证正确率；本轮仅验证本地及模拟请求，没有真实付费调用、账号能力复验或数学质量校准。

验证包括原有测试、合成彩色/矢量资料、字段拖选与保存、请求体图像字节哈希及预算失败保护。执行 `npm.cmd run test:reference-browser` 可复核新增浏览器流程；真实资料、截图与本机验收记录不随源码提交。
