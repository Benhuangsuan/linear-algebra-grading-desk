# 2.9.0 阶段修改说明（成果包含于v2.11.0）

本阶段未单独发布Release；已验收成果随[v2.11.0](v2.11.0.md)发布。以下保留功能变化说明，模拟回归不代表任意数学材料的真实AI准确率。

- 作业范围支持自由中文说明，改变范围说明不再自动触发重新整理；PDF 章节以材料标题、文件名和人工核对为准。
- 免费整理支持补充章的小节、讲义题和附加题。同节两类题组重号、不同小节的同号题分别保存；跨页解答沿用原题，保留来源页及图形。题目窗口可人工指定小节、题组与参考页。
- 材料明确要求全部批改时，新候选均采用“批改正确性”；漏做默认扣0.2、错误默认扣0.1。解答题仍默认整题一个单元，不因证明方向字母自动独立计分。普通教材默认奇偶策略和人工修改保持有效。
- 自动、纯文字与 AI 辅助整理共用题目身份；AI 候选检查题组、章节和页码。学生没写题组时，批改结合内容、图形和顺序定位，无法确定则留待人工核对。
- 已上传材料即使旧版未整理出题，也可主动点击“整理题目清单”，检查、采用并保存。已有题目与成绩不会在启动时自动覆盖，不需要删除原文件或重建作业。

历史无题组记录的身份和评分快照保持兼容；没有数据库迁移或批量重算。修改当前规则不会自动改历史成绩。AI 建议仍须助教复核，不保证任意字迹、布局或证明都能准确判断。

开发验证覆盖合成自动化测试、浏览器流程、普通教材和补充章结构；私人参考材料及授权试批证据仅留本机，不包含在仓库中。安装与数据保护要求见 [README](../../README.md) 和 [部署指南](../助教本地部署与使用指南.md)。升级请按[安全升级指南](../从v2.8升级到v2.11.md)执行。
