# 2.10.0 阶段修改说明（成果包含于v2.11.0）

本阶段未单独发布Release；已验收成果随[v2.11.0](v2.11.0.md)发布。以下保留功能变化说明，模拟回归不代表任意数学材料的真实AI准确率。

- 修复章节标题与题号列表同一行时被提前跳过的回归，保留没有逐题参考解的完成性题。继续支持教材章节和补充章、同号不同题组、跨页和非数字题目标识。
- 上传只保存文件；默认选择“AI 识别（可能收费）”，不会自动请求。免费自动整理和按文字整理仍可明确选择，无Key或付费关闭时也能使用。
- AI参考整理可一次选择多份PDF，全原页参与；仅填写一个本次总预算。预估绑定材料、规则版本、模型、预算及渲染方式，明确开始才授权传输和费用。学生批改原有隐私确认不变。
- 自动按文件和原页分批，重叠上下文合并；校验页覆盖、题号集合、检查方式、章节、小问与图形页。发现不完整/冲突不当作成功；分类不确定的题需人工确认。
- 任务草稿、进度和费用保存在本机新增的参考任务表；取消阻止尚未发出的请求，中断不自动续费。累计已发生费用与未知用量预留用于后续预算门禁，失败不自动重试。
- 在结果中查看各文件数量、题目类型、识别依据及原页链接。采用后仍需保存设置，已有人工规则和历史成绩保留；原评分账本不迁移或重算。
- 兼容仅列题号的完成性题返回的已知题型别名，以及无小问时省略空列表的响应；仍拦截缺少真实小问、不完整页面或错误检查方式的结果。逐题预览中的长公式可以换行，避免撑宽窄屏窗口。
- 作业范围示例统一为“可自由填写，例如1.1-1.3，或补充章1-4”。

原数据库增加独立的参考任务表，不迁移学生成绩或规则快照。升级前应完整备份并在独立数据副本验收，见[安全升级指南](../从v2.8升级到v2.11.md)。
