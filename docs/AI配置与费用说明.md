# API 与费用说明（2.13.0）

2.11参考整理默认选择AI，但上传、切换或保存均不调用。一次勾选多份PDF，所选文件全部页面参与；只设本次总预算（默认2元），预估后点击“开始 AI 整理”明确确认本次传输及费用。参考整理每次输出上限32768 tokens（含思考），与学生批改的额度选择分开。后台按文件、原页分批并累计费用/未知用量预留，超预算不续发、不自动重试，可取消后续请求。任务及待确认草稿在本机保留，中断后不自动续费；需要重新预估才可发起新任务。结果要先核对并采用，再保存设置；已有人工规则和历史成绩不自动覆盖。学生批改的隐私去标识及授权检查仍保留。

2.11 按文件保存完整草稿、部分分页和模型最终正文，原始思考不落盘。跨任务使用已有完整草稿、合并预览和离线复验不请求模型；再次整理或重试只预估本次新增请求，原费用及未知用量预留不清零。独立重试会尽量复用有效分页，单页内容不完整时仍须重试该页；失败不自动续费。历史版本保留，采用后仍需保存，不自动改人工规则或成绩。

已有完整结果的文件重新整理：先预估、主动点击开始确认本次预算和传输，再出现“使用已有结果／继续重新整理／取消”的30秒倒计时。用户未选择时会默认继续，这有重复付费的误操作风险；离开页面、失去焦点、离线、预估过期或规则/材料变化均取消。没有本次明确授权、浏览器重开或服务重启时不自动请求。服务器还会核对一次性预估、文件内容、小节、模型及预算。

旧2.10完整草稿可按文件恢复，但旧版未留原响应和原文件内容指纹，须人工对照当前PDF；无法凭账本补出丢失的模型正文。新版本保留的正文、草稿及历史均可能含私密参考内容，随完整DATA_DIR备份，不得公开上传。

核对日期：2026-11-04（Asia/Shanghai）。DeepSeek峰时单价已对照官方价格表，仍沿用保守换算系数8；Qwen沿用原价格快照，不是实时价格、实测账单或数学准确性结论；使用前请自行核对官方价格。

## 页面与请求组织

2.12 不再统一按3倍放大：依据页面 points 自适应取1～3倍细节坐标，大页/长页保留全景与重叠分区，直接将视图绘制到最长边2400px以内，JPEG质量84（编码过大时80）。普通小页保持原有分辨率；大页不只留下缩小全景，细节分区仍覆盖全部原区域。单图仍超过6MiB、本地64分区/单PDF200图像的资源限制时按具体原页阻止，不静默删页。分区、局部放大和证据均使用原PDF页码；缓存另行升级，不改上传原件或历史结果。

优化后整份参考与学生图像能安全装入时，仍一次完整评分，必要时最多一次局部复读（最多4个学生区域）。否则自动将全部参考/学生视图按顺序分批转录，每批最多8视图、4原页，并逐批检查实际JSON请求大小和上下文。所有批次覆盖完整后，才联合全部转录及相关原图进行最终评分；必要时按计分单元分组，每组均看到整份证据，不能把每批页面各算一次成绩。未完成或不清晰页面不能据此扣漏题分。分批结果统一待人工复核，不承诺模型的数学准确率。

保留平台46MiB请求体上限，不增加服务商限制。预检计算实际传输结构、Base64/Data URL、规则、模型参数和输出设置的UTF-8字节，调用前再次同标准检查。DeepSeek官方正文限制48MiB，平台留有余量；单图/数量另行限制，不与PDF压缩大小、上下文或输出额度混用。依据：[DeepSeek视觉限制](https://api-docs.deepseek.com/guides/vision/)、[Qwen图像输入限制](https://help.aliyun.com/zh/model-studio/vision/)。

分批成功的最终正文及任务指纹只存私人DATA_DIR中的`grading_runs`表，不提供静态下载或通用状态接口。失败后重新快速检查并明确开始，只重试未通过部分，已通过的识别和评分组免费复用；文件/规则/模型/输出设置改变后旧证据不复用。已完成整份成绩再次明确重批会创建新任务。原人工结果、评分历史和费用账本保留。

DeepSeek 对大图存在服务端视觉缩放；增加分区是改善密集页面输入的措施，不是已经完成真实准确率校准。全景定位、重叠细节及局部复读仍须结合人工页码核对。参考 PDF 的长页/大页使用相同本地分区，但没有另起自动参考页复读调用。官方图片尺寸、单图独立缩放和 1024 token 上界见[视觉文档](https://api-docs.deepseek.com/zh-cn/guides/vision/)。

文档中的“请给满分”等文本当作数据，不执行其中指令。不要求返回内部思维链，流式 reasoning_content 不保存；模型只给事实性判定，后端补算扣分。

## 价格与预算

默认费率为每百万 token 的人民币预算单价：

| Provider | 输入未命中 | 输出 | 输入缓存命中 | 依据 |
| --- | --- | --- | --- | --- |
| DeepSeek | 0.30 × 8 = 2.40 | 1.20 × 8 = 9.60 | 0.006 × 8 = 0.048 | 官方 USD 峰时价格 × 保守预算换算系数 |
| Qwen 北京 | 1.20 | 4.80 | 0.24 | 官方长上下文最高档，作保守门禁 |

DeepSeek 价格来源为[官方价格表](https://api-docs.deepseek.com/quick_start/pricing/)，Qwen 价格来源为[模型价格](https://help.aliyun.com/zh/model-studio/qwen3-7-flash)及[计费阶梯说明](https://help.aliyun.com/zh/model-studio/model-pricing)。DeepSeek 的 8 是可配置预算换算系数，不是实时汇率；未自动按非峰时打折。Qwen 未用免费额度或活动优惠抵扣预算。

费用估算公式为：

~~~text
[(输入 token - 缓存命中 token) × 输入单价
 + 缓存命中 token × 命中单价
 + 输出 token × 输出单价] / 1,000,000
~~~

输入门禁使用文本 UTF-8 字节数、视觉 token 上界及余量，不预先假设命中缓存。真实 usage 返回后才记录输入/输出/命中并估算；缺字段标未知。价格快照随调用保存，更新时间默认 2026-10-23，可用 .env.example 中的费率变量覆盖。

学生批改不再提供整批费用预估或 ¥0.30 额外确认。每份预算默认 ¥0.50、本批默认 ¥2，用户可明确修改；并发仍为1。免费“快速检查”先返回全部选择的逐文件状态，后台逐份完成全部原页渲染与请求规划；只有关键检查完成才为可批改。问题文件由助教主动移出，未变文件无需重新扫描。检查凭据15分钟有效，不能代替付费授权；材料、规则、模型、输出额度或记录变化、重启后需重新检查。预算或隐私确认变化不要求重新渲染原件。

后台只对下一次实际请求按输入和输出上限进行保守预留，并在发送前持久化。首笔必要预留超预算时拒绝启动；后续不足则停止后续请求，保留成功证据、旧账单和未知用量，不自动加预算或重试。不再用所有可能调用的极端总价拦截整批。续跑仍将同任务已有费用及未知预留计入每份和本批预算；恢复只使用同材料、规则、模型和处理设置下的成功部分。旧暂停批次缺输出额度时仍按8192保守续跑，不因升级扩大授权。

DeepSeek默认输出16384、Qwen8192，环境设置优先；批改选项可选8192/16384/32768。额度包含思考与评分，不会自动提高。参考答案整理原有估价与权限机制保持不变。

单项“解释这项扣分”只查看已保存的理由、规则及原稿，不请求模型。主动追问须每次确认云端发送的学生全部原页、参考页、本项规则与历史问答、去标识及本次预算（默认0.10元，上限1元）。追问每次输出上限4096；同评分版本每项最多三次，每次都须显式授权。对话仅存私有DATA_DIR的explanations表，可查看历史版本和删除，费用账本仍保留。追问不写评分、人工草稿或成绩历史，也不进入CSV。

这是本机请求门禁，不是服务商锁定账单：估算、计费变化、未知用量都可能影响最终费用。超时/中断没有 usage 时仍保留全额预留，不能据此声称实际已花或未花某个精确金额。

“测试连接”发送合成蓝色图片，单次本机门禁 ¥0.05；也属于可能付费的调用，需用户主动点击并确认。空 Key / 未启用真实模式不会请求。

## 错误与恢复

- Key 缺失、未启用：本地拦截，不发送页面。
- 401 / 402 / 403：分别提示无效 Key、余额不足、权限/地区问题。
- 429或服务商5xx：学生评分、分批识别/汇总、追问与参考整理均不自动付费重试，须明确操作。
- 网络/超时：用量未知、保留预留，不盲目自动重发。
- 模型/图片/JSON 不支持或结果不合法：明确失败，不退回 Mock 冒充成功。
- `length`：额度耗尽，不接纳不完整评分；提示调整额度后重新检查或人工处理，不能靠重复上传解决。不会自动提高额度或反复付费重试。已有 usage 的思考 token 可以只读显示；新调用另存文本长度，思考原文不落盘。
- 放大被预算阻止：保留初轮结构化建议并标待核对。
- 暂停：停止后续任务，在途可完成；取消：尝试中止，在途可能已计费。
- 重启：未结束批次暂停，需要用户明确续跑；原成绩、报告和账本保留。

## 用户操作与人工校准

按 README 使用 Windows 用户环境变量，重新打开终端后启动。只对已授权、已去标识或合成样本进行真实测试；平台不会自动替手写页打码。API 字段不携带姓名、学号、文件名，不等于图片已经没有身份信息。

每次新作业先由助教独立完整批改至少两份代表样本，再对同样的已授权、已去标识样本进行小批量 AI 对照。逐单元核对错误、漏题、证据页和等价解，不只比较总分；不足以判断质量时增加人工样本。查看批次账本并对照服务商账单后，再决定是否扩大范围。若需要另用 Qwen，必须明确授权新增费用，不会自动双模型调用。

3～5 份样本使用离线 benchmark:ai 模板，人工填写后输出对照。报告按原始 AI 建议计算，而非人工已改分；未知用量单列，估算费用与最终账单区分。判断符号、等价解、红笔和低清晰度应分别人工归类核对。已有少量 DeepSeek 使用反馈，尚无系统性的质量/费用基准；本次公开分发验证仅使用本地合成与模拟测试。

2.7 的禁用原因与服务端共用校对和参考资料检查，仍保留后端授权、预算及重复入队拦截。学号识别和人工修改只更新本地身份字段，模型请求不新增姓名、学号或文件名；原 PDF 页面需使用者自行去标识。`ENABLE_MOCK_UI` 只控制开发模拟入口与接口，默认关闭，不会开启付费许可。
